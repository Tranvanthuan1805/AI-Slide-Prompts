# ✨ Beautiful.ai Prompts — Smart Layout Slides

> **Tool:** [Beautiful.ai](https://beautiful.ai) | **Điểm mạnh:** Smart slide layouts tự động adjust, professional look nhanh

---

## Cách dùng Beautiful.ai

Beautiful.ai dùng "Smart Slides" — layout tự động điều chỉnh khi thêm/bớt content.
Dùng AI Assistant (Ctrl+K hoặc nút ✨) để generate nội dung.

---

## Prompt 1: AI Assistant — Business Presentation

```
Create a [NUMBER]-slide business presentation titled "[TITLE]"

Company/Project context: [MÔ TẢ NGẮN]
Audience: [KHÁN GIẢ]
Key message: [1 CÂU TÓM TẮT ĐIỀU MUỐN KHÁN GIẢ NHỚ]

Slides needed:
1. Title slide with tagline
2. Problem/opportunity slide with 3 key pain points
3. Solution overview with visual comparison
4. How it works (3-step process)
5. Key benefits (3-4 benefits with icons)
6. Social proof or case study
7. Team slide
8. Next steps / Call to action

For each slide: punchy headline, 2-3 supporting points, suggested visual type
(chart / photo / icon / diagram / comparison table)

Tone: [Confident and data-driven / Inspiring and visionary / Educational and clear]
```

---

## Prompt 2: Competitive Analysis Slide

```
Create a competitive analysis section for my presentation about [PRODUCT/SERVICE].

My company: [MÔ TẢ]
Competitors to include: [TÊN ĐỐI THỦ 1], [TÊN ĐỐI THỦ 2], [TÊN ĐỐI THỦ 3]

Comparison criteria:
1. [TIÊU CHÍ 1 — ví dụ: Price / Speed / Features / Support]
2. [TIÊU CHÍ 2]
3. [TIÊU CHÍ 3]
4. [TIÊU CHÍ 4]

Create:
- 1 overview comparison matrix slide
- 1 "where we win" slide (highlight our unique advantages)
- 1 positioning statement slide

Important: Frame the comparison so our strengths are clearly visible without
being dishonest about competitors. Use visual icons (✓/✗/~) for quick scanning.
```

## Prompt 3: Data & Analytics Report

```
Create a data-driven report presentation on [TOPIC/PROJECT].

Data to present:
- Key metric 1: [METRIC NAME + VALUE + CONTEXT]
- Key metric 2: [METRIC NAME + VALUE + CONTEXT]
- Key metric 3: [METRIC NAME + VALUE + CONTEXT]
- Trend data: [MÔ TẢ XU HƯỚNG]

For each data point, suggest:
1. Best chart type (bar / line / pie / scatter / funnel / number card)
2. What story the data is telling (not just the numbers, but the INSIGHT)
3. How to highlight the most important number on the slide
4. Annotation/callout to add context

Report structure:
- Executive summary (3 key numbers, big and bold)
- Deep dive sections (1 chart per slide, 1 insight per chart)
- Trends & patterns
- Recommendations (data-backed, specific, actionable)
- Appendix (methodology, full data tables)
```

## 💡 Beautiful.ai Tips

| Smart Slide Type | Tốt nhất cho |
|---|---|
| **Comparison** | Đối chiếu features, options, A vs B |
| **Timeline** | Process, history, roadmap |
| **Team** | Giới thiệu members với photo + role |
| **Big Number** | Highlight 1 metric ấn tượng |
| **Agenda** | Opening / table of contents |
| **Quote** | Testimonial, memorable statement |
| **Icons & Text** | Benefits list, features overview |
| **Charts** | Tích hợp real-time từ Google Sheets |
