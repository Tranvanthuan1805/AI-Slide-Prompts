# 🎨 Gamma.app Prompts — Tạo Slide Tự Động Đẹp Ngay

> **Tool:** [Gamma.app](https://gamma.app) | **Điểm mạnh:** Tự động tạo slide đẹp từ text/outline trong 30 giây

---

## Cách dùng Gamma

1. Vào **gamma.app** → Chọn **"Generate"**
2. Paste prompt vào ô text
3. Chọn theme phù hợp
4. Edit và fine-tune

---

## Prompt 1: Tạo slide nhanh từ outline

```
Create a professional presentation about [TOPIC] with the following structure:

## [Slide 1 Title]
Hook: [opening statement that captures attention]
Key point: [main message in 1 sentence]

## [Slide 2 Title]
[2-3 bullet points, each starting with a strong action verb]
Visual: [describe what kind of image/chart would work]

## [Continue for all slides...]

Design notes:
- Use [modern/minimalist/bold/academic] style
- Color mood: [professional blue / energetic orange / calm green / sophisticated dark]
- Typography: Clean, readable, mix of large headers and small body text
- Each slide should have breathing room — no text walls
```

## Prompt 2: Academic presentation (Gamma format)

```
Generate a [NUMBER]-slide academic presentation on "[TOPIC]"

Target audience: [University students / Professors / General public]
Purpose: [Inform / Persuade / Teach / Inspire]
Duration: [X minutes]

Content outline:
1. Opening hook — surprising fact or question about [topic]
2. Why this matters — real-world relevance
3. Background — only what's necessary to understand the main content
4. [Main section 1]: [Key concept + visual metaphor suggestion]
5. [Main section 2]: [Key concept + data visualization idea]
6. [Main section 3]: [Key concept + case study]
7. Analysis & implications
8. Counterarguments & nuances (don't ignore complexity)
9. Takeaways — 3 memorable points, not a summary
10. Discussion question for the audience

Style: Academic but engaging. Avoid bullet-point overload.
Use callout boxes for key definitions. Include suggested icons for each section.
```

## Prompt 3: Business pitch (Gamma format)

```
Create a compelling startup pitch deck for [COMPANY NAME]:

Problem: [Describe the problem in 1-2 sentences]
Solution: [Your solution in 1 sentence]
Target market: [Who are your customers]

Slide structure:
1. Cover — company name + tagline (make the tagline memorable, not generic)
2. The Problem — use a story format, 1 specific person experiencing this problem
3. Solution — focus on the "aha moment", not the features
4. How it works — simple 3-step visual flow
5. Market size — visual breakdown with bottom-up logic
6. Business model — 1 clear revenue diagram
7. Traction — most impressive metrics in large, bold numbers
8. Team — photos + 1 unique qualifier per person (not job titles)
9. Competitive advantage — visual matrix, not a table
10. The ask — clear, specific, with milestone milestones

Design: Clean and investor-ready. Use large numbers for impact.
Dark or light theme depending on [formal/creative] context.
```

## Prompt 4: Workshop / Training slides

```
Design an interactive workshop presentation on "[WORKSHOP TOPIC]"

Duration: [X hours]
Participants: [NUMBER] people, [beginner/intermediate/advanced] level
Goal: By the end, participants will be able to [SPECIFIC OUTCOME]

Structure (mix content + activities):
1. Welcome & icebreaker — include an interactive warm-up activity
2. Agenda — visual timeline, not a list
3. [Module 1 — 20 mins]: [Topic] + hands-on activity
4. [Module 2 — 20 mins]: [Topic] + group discussion prompt
5. [Module 3 — 20 mins]: [Topic] + individual reflection
6. Practice session — clear instructions slide
7. Debrief — guided reflection questions
8. Key takeaways — 3 insights they can act on TODAY
9. Resources & next steps
10. Closing energizer

Design note: Use warm, engaging colors. Include activity timer icons.
Make instruction slides extra clear — large font, numbered steps.
```

## 💡 Gamma-specific tips

| Tip | Detail |
|---|---|
| **Thêm icons** | Viết `[icon: lightbulb]` trong prompt → Gamma tự thêm icon |
| **Charts** | Mô tả dữ liệu → Gamma tự tạo chart đẹp |
| **Cards layout** | Thêm "use card layout for this section" |
| **Image prompts** | Viết `[image: a person looking at data on a screen, modern office]` |
| **Theme chọn** | "Minimal" cho professional, "Beam" cho creative, "Luxe" cho premium |
