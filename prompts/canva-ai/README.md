# 🖼️ Canva AI Prompts — Visual & Design-First Slides

> **Tool:** [Canva](https://canva.com) → Magic Design / Magic Write | **Điểm mạnh:** Visual đẹp, brand consistent, creative layouts

---

## Cách dùng Canva AI

1. **Magic Design**: Canva → "Create a design" → "Presentation" → paste prompt
2. **Magic Write**: Mở slide → Click text → "Magic Write" → prompt
3. **Text to Image**: Insert → AI Image Generator → describe hình ảnh muốn tạo

---

## Prompt 1: Magic Write — Tạo nội dung slide

```
Write slide content for a [NUMBER]-slide presentation about [TOPIC].

For each slide, provide:
- A punchy headline (max 8 words, use power words)
- 3 bullet points (max 10 words each, start with verbs)
- One key statistic or quote to highlight

Tone: [Professional / Inspirational / Educational / Bold and direct]
Avoid: Jargon, passive voice, generic phrases like "in conclusion" or "as we can see"

The presentation is for [AUDIENCE] who care most about [THEIR PAIN POINT / GOAL].
Make every word earn its place on the slide.
```

## Prompt 2: Canva AI Image Generation — Visual Concepts

```
Tôi cần tạo hình ảnh cho slide về [CHỦ ĐỀ]. Mô tả concept:

Hình 1 (Cover slide):
[Style: flat illustration / photo-realistic / abstract / minimalist art]
[Subject: mô tả cụ thể cần có trong hình]
[Mood: professional và inspiring / playful và energetic / calm và trustworthy]
[Color palette: [MÀU SẮC] — hex codes nếu có]

Hình 2 (Problem slide):
[Mô tả visual metaphor cho vấn đề — ví dụ: "tangled wires representing complexity"]

Hình 3 (Solution slide):
[Mô tả visual metaphor cho giải pháp — ví dụ: "clear path through a forest"]

Hình 4 (Impact slide):
[Data visualization concept — ví dụ: "growing bar chart with people icons"]

Lưu ý: Consistent style across all images, same color palette.
```

## Prompt 3: Brand-consistent presentation

```
Create a brand-consistent presentation for [BRAND/PROJECT NAME].

Brand guidelines:
- Primary color: [HEX CODE hoặc mô tả màu]
- Secondary color: [HEX CODE]
- Font style preference: [Modern sans-serif / Classic serif / Playful rounded]
- Brand personality: [3 adjectives — ví dụ: bold, innovative, trustworthy]
- Logo placement: [top-left / centered / none]

Content topic: [CHỦ ĐỀ SLIDE]
Number of slides: [SỐ SLIDE]

For each slide suggest:
1. Layout type (title slide / two-column / full-bleed image / infographic / quote)
2. Visual element (icon set / photo style / illustration style / chart type)
3. Text hierarchy (what's BIG, what's medium, what's small)

Design principle: Every design choice should reinforce the brand personality.
Avoid: Templates that look generic, clipart, overused stock photo styles.
```

## Prompt 4: Infographic slide

```
Giúp tôi thiết kế nội dung cho infographic slide về [CHỦ ĐỀ].

Dữ liệu/thông tin cần visualize:
[LIỆT KÊ DATA, FACTS, HOẶC PROCESS CẦN HIỂN THỊ]

Chọn loại infographic phù hợp nhất:
□ Timeline (cho process/history)
□ Comparison (cho A vs B)
□ Statistical (cho data/numbers)
□ Flow chart (cho process/decision)
□ Hierarchy (cho organization/levels)
□ Geographical (cho location data)

Với loại đã chọn, thiết kế nội dung:
- Title: [TITLE]
- Main sections: [MỤC CHÍNH]
- Key numbers to highlight: [SỐ LIỆU QUAN TRỌNG]
- Color coding suggestion: [MÀU CHO TỪNG SECTION]
- Icon suggestions: [ICON PHÙ HỢP]

Output: Mô tả chi tiết layout để dễ recreate trong Canva.
```

## 💡 Canva AI Hacks

| Hack | Cách làm |
|---|---|
| **Resize instantly** | Magic Resize → adapt 1 slide thành nhiều format |
| **Consistent icons** | Chỉ dùng 1 icon pack (tìm trong Elements → filter by style) |
| **Photo feel** | Dùng Canva AI Photo Editor → "Make photo look like [style]" |
| **Brand kit** | Save colors + fonts vào Brand Kit → apply instantly |
| **Background remover** | Upload ảnh → Edit photo → BG Remover → overlay trên slides |
